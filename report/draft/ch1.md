# 摘要

本作品面向赛题给定的 E203 SoC 平台，为 KWT-1 关键词识别模型的十二层 Transformer 编码器设计了一款固定功能推理引擎 KSE（KWT Stream Engine）。KSE 把网络形状、层序和数值格式全部硬连线，没有指令流；参数在共享 SRAM 中边装载边计算，层内各阶段尽量重叠执行。

KSE 采用 A8/W4 全整数量化方案：逐通道 2 的幂尺度、24 位累加、Q15 指数表加 P7 概率的 Softmax、Q12/Q12 的 LayerNorm，以及 GELU 中段查表。RTL 输出与软件数值模型在每一个中间张量上逐位一致。在 SMIC 40 nm、150 MHz 条件下，主要结果如下表。

表 0-1 主要指标

| 指标 | KSE |
| --- | ---: |
| 单任务周期（十二层编码器，含参数装载与门铃） | **163,328** |
| 吞吐（任务/秒） | **918.4** |
| 计分面积（mm²） | **1.237** |
| 整 SoC 平均功耗（mW） | **123.41** |
| 单任务能耗（µJ） | **134.38** |
| Top-1（测试集 4890 条；FP32 为 97.61%） | **96.97%** |

KSE 的单任务周期只比单口事务下限高 0.29%：共享 SRAM 是 System Bus 上一个普通 32 位单口从设备，加载器的 80,592 字写入与 DMA 的 80,592 字读取必须串行通过同一个从口，加上 1,584 字输出写、1 次完成标志和 81 笔门铃发布，窗口内共 162,850 笔事务，实测 163,328 拍。报告第 3 章给出体系结构设计，第 4 章说明 SoC 集成与验证，第 5 章给出综合与 PPA 评测，第 6 章总结创新点。

**关键词**：KWT-1；Transformer 加速器；固定功能 ASIC；全整数量化；边载边算；PPA

# 1 设计概述

## 1.1 赛题与平台约束

赛题要求在 E203 SoC 平台上完成 KWT-1 编码器的加速。研究生组需完成全部七项任务，一个任务定义为完成一次十二层编码器计算并写回结果，输入与输出均为 99×64 的 token 矩阵。关键词识别任务上，已有专用芯片采用 ΔRNN 分类器，把单次推理能耗做到 36 nJ、面积做到 0.78 mm² [2]；本赛题的十二层 Transformer 编码器在计算量和参数规模上都显著更大。与设计决策直接相关的约束有以下几条：

- **平台固定**：E203 处理器、512 KB 共享 SRAM、32 位系统总线，系统时钟 150 MHz；共享 SRAM 必须是 System Bus 上一个普通的单口从设备，加速器经总线接入；新增加速器（含接口逻辑和内部 SRAM 宏）面积不超过 2.25 mm²。
- **计时口径**：每个任务从输入和参数开始装载起计时，到结果写回为止；任务开始前清空参数缓存，因此十二层参数的传输开销每个任务都要统计一次。
- **精度门槛**：Top-1 相对浮点参考下降不超过 2 个百分点，且 RTL 须与本作品提交的软件数值模型一致。
- **效率计分**：吞吐、单任务能耗、面积按与本组最优设计的比值计分。

这些约束意味着：单任务周期数同时决定吞吐和能耗两个评分项；参数装载是每个任务不可回避的固定成本，而且加载器写与引擎 DMA 读只能分时共用同一个 32 位从口；面积在不超上限的前提下权重较小。这些是 KSE 体系结构设计的出发点。

## 1.2 设计路线

KWT-1 的编码器结构固定、层序确定，且赛题要求每个任务都完整装载一遍参数。因此本作品选择固定功能 ASIC 路线：把网络形状、层序和数值格式直接固化成电路，用定序器和硬连线地址生成代替指令流；把“加载器写 80,592 字、DMA 读 80,592 字”视为每个任务必须串行通过单口的 162,769 笔必然事务，围绕这条事务流组织数据通路，让计算与参数流完全重叠。

设计按以下步骤展开：

1. **数值底座（第 2 章）**。分析 KWT-1 的算子形状与计算量，确定 A8/W4 全整数量化方案、整数非线性实现和逐位一致的软件模型。
2. **KSE 引擎（第 3 章）**。设计 1024 MAC 的计算阵列、驻留加流式的矩阵调度、两段式注意力、专用非线性单元、单口共享 SRAM 的加载器与 1024 字门铃流控，以及层间调度重叠，并用评分函数驱动的消融实验确定最终配置（PF128、SM/LN 8 路）。
3. **SoC 集成与验证（第 4 章）**。把共享 SRAM 作为 System Bus 上一个普通单口从设备，用唯一仲裁器合并 CPU、加载器和 NPU DMA，接入 E203、PLIC 与门铃寄存器，完成从单元级到十二类 SoC 回归的逐位验证。
4. **综合与 PPA 评测（第 5 章）**。在 SMIC 40 nm、150 MHz 下给出同一配置的时序、面积、吞吐、功耗与能耗结果。
