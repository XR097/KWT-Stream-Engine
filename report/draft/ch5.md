# 5 综合与 PPA 评测

本章在 SMIC 40 nm 工艺下给出 KSE 的时序、面积、性能和能耗结果。所有指标都来自同一份 RTL、同一个完整 SoC 综合网表和同一组约束。

## 5.1 评测条件

服务器上的 SRAM 宏只提供 TT 1.10 V 25 °C 一组模型。为了让标准单元和 SRAM 宏处于同一工艺角，标准单元也选用同一条件。评测条件如表 5-1 所示。

表 5-1 评测条件

| 项目 | 配置 |
|---|---|
| 工艺与工作条件 | SMIC 40LL RVT，TT / 1.10 V / 25 °C |
| SRAM 宏 | 128×16、1024×16、4096×16 位单口宏 |
| 时钟 | 150 MHz，理想时钟，时钟不确定度 0.1 ns |
| 输入 / 输出延迟 | 时钟周期的 20% |
| 寄生参数 | 布线前，无 SPEF |
| 工具 | Design Compiler 综合，PrimeTime 时序分析，PrimePower 功耗分析，VCS 仿真 |

## 5.2 时序

在完整 SoC 综合中，加速器的 setup 和 hold 裕量均为正，满足 150 MHz。时序检查的范围包括引擎、包装与 DMA、总线仲裁器、共享 SRAM 控制器和 PLIC。

表 5-2 时序结果

| 路径范围 | setup 裕量（ns） | hold 裕量（ns） |
|---|---:|---:|
| 加速器 | +0.010 | +0.014 |
| E203（含 TCM，固定平台） | 0.000 | +0.026 |

加速器的 setup 关键路径在 LayerNorm 的流水除法器中，可以通过增加除法器每级的寄存深度进一步放宽。

## 5.3 面积

计分范围是新增的加速器逻辑、接口逻辑和加速器内部的 SRAM 宏。KSE 的计分面积为 **1.237 mm²**，占 2.25 mm² 上限的 55.0%，构成如图 5-1 所示。MAC 阵列占 49.0%，两块行存储占 23.7%，二者合计超过七成；LayerNorm 和 Softmax 单元分别为 0.152 mm² 和 0.070 mm²；控制、DMA 与总线接口合计只有 0.016 mm²（1.3%），这正是去掉指令流以后控制开销很小的直接体现。内部 40 个 SRAM 宏约占计分面积的 25%。固定平台（E203、TCM、512 KB 共享 SRAM 和外设）为 2.305 mm²，不计分，SoC 总面积为 3.542 mm²。

## 5.4 性能

计时窗口从加载器的第一笔总线写开始，到 E203 写完成标志结束，包括全部输入和参数的传输、引擎计算、输出写回和 CPU 调度。KSE 的数据通路和调度与数据值无关，12 个任务的周期都是 163,328 拍，150 MHz 下的吞吐为 918.4 任务/秒。

单任务周期中，引擎从接收第 0 层命令到第 11 层完成共 163,126 拍，CPU 启动调度 47 拍（与参数装载重叠），完成后 CPU 处理中断并写完成标志 154 拍。窗口内共享 SRAM 端口忙 162,850 拍，正好等于式 (3-1) 的事务下限，端口利用率为 99.7%。换句话说，引擎计算和 CPU 调度几乎全部隐藏在端口流量之后。

## 5.5 功耗与能耗

功耗采用基于仿真活动的方法评估：在实际时钟周期下仿真 12 个任务，分别记录每个任务计时窗口内整个 SoC 的翻转活动，合并成一份活动文件后，由 PrimePower 在综合网表上反标计算。统计范围包括 E203、加速器、互连和全部 SRAM 宏的动态与静态功耗。改变未反标信号的默认翻转率后结果不变，说明活动文件覆盖完整。单任务能耗按下式计算：

$$ E_{\mathrm{task}} = \bar{P} \cdot \frac{C}{f_{\mathrm{clk}}} = 123.41\,\mathrm{mW} \times \frac{163{,}328}{150\,\mathrm{MHz}} \approx 134.38\,\mu\mathrm{J} $$ (5-1)

表 5-3 功耗与能耗

| 项目 | KSE |
|---|---:|
| 整 SoC 平均功耗（mW） | **123.41** |
| 单任务能耗（µJ） | **134.38** |

在整 SoC 功耗中，引擎（含内部 SRAM 宏）占 94.37 mW，约 76%；共享 SRAM 为 5.10 mW；E203 处理器核在等待期间执行 WFI，大部分时钟被门控，只有 1.02 mW；其余为互连、TCM 和平台逻辑。
