# 7 总结与展望

本文为 KWT-1 关键词识别模型设计了固定功能推理引擎 KSE，并把它集成进 E203 SoC。我们首先从平台约束出发，指出在单口共享存储、每个任务都要重新装载参数的条件下，任务周期受端口事务数限制；据此确定的设计目标是让计算完全隐藏在参数流之后，而不是追求峰值算力。围绕这一目标，我们设计了 W4A8 全整数数值方案、权重驻留的 1024 MAC 阵列、片内两段式注意力、专用非线性流水线和写指针门铃驱动的边载边算机制，并以评分函数为目标完成了设计空间探索。在 SMIC 40 nm、150 MHz 条件下，KSE 以 1.237 mm² 的计分面积完成一个任务需要 163,328 拍，吞吐为 918.4 任务/秒，单任务能耗为 134.38 µJ，测试集 Top-1 精度下降 0.63 个百分点。

后续工作主要有三个方向：一是推进后端实现，在布局布线之后复核时序和功耗；二是继续推进独立验证，使覆盖率达到闭合，并在 SoC 层次加入随机总线反压；三是在平台允许的情况下研究参数压缩和片内参数复用，从根本上降低端口事务的下限。
