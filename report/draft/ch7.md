# 7 总结

本作品在 E203 SoC 平台上为 KWT-1 十二层编码器设计并实现了一款固定功能推理引擎 KSE。KSE 把网络结构、层序和参数调度固化进电路，在计分面积 1.237 mm² 内以 163,328 个周期完成一个任务，吞吐约 918.4 任务/秒，单任务能耗 134.38 µJ，任务周期只比共享 SRAM 单端口的事务下限高 0.29%，Top-1 相对浮点参考在完整测试集上下降 0.63 个百分点。

KSE 达到这一效率的关键有三点：第一，把共享 SRAM 做成 System Bus 上一个普通 32 位单口从设备，用唯一仲裁器合并 CPU、参数加载器和 NPU DMA，用 1,024 字门铃发布进度并只读已提交字，使 162,850 笔事务几乎占满整个窗口；第二，用 1,024 个 9×8 位乘法器组成驻留加流式的矩阵阵列，使权重驻留、激活流式，避免中间结果往返共享存储；第三，用专用流水线实现 Softmax、LayerNorm 和 GELU，并通过层内、层间调度重叠把计算藏进参数事务流。最终任务周期只比单口事务下限高 0.29%。

全整数数值方案与逐位一致的验证闭环，使软件模型上测得的精度可以直接代表硬件精度。对网络结构固定、每个任务都要重新装载参数的场景，固定功能硬连线是合适的选择；若模型或数值规格发生变化，则需要重新设计数据通路和参数打包流程。
