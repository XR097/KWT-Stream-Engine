## 复现、偏离与限制

入口：`python -B quantization/scripts/run_asic_numerics.py --data-root <数据根> --repo-root . --reference-root <只读上游repo> --workers 12 --resume`；设置 CUDA_VISIBLE_DEVICES=-1、OMP/OPENBLAS/MKL_NUM_THREADS=1，以及 KWT_ASIC_MAC_LIBRARY 为本次原生整数核（`native_mac.c`）的共享库。可用 --stage 按阶段恢复；FP32 每32条、整数每8条落盘进度，身份改变拒绝混用。原生核是为逐项前缀计宽新增的可选整数加速，源码为 `quantization/native_mac.c`，无运行时浮点；未加载时回退 NumPy 完整前缀循环。偏离计划：角色重合时补入不同的高 J 点；空子模块使用只读上游路径；首次 worker 启动因系统提交内存不足而失败，尚无整数测量结果，随后改用共享只读 mmap 和8条批次、隔离 TF 准备子进程，通过全套测试并重新冻结后恢复。被中止身份留档，不混入最终测量。没有训练/微调，没有修改第三方源码，没有写旧缓存。

完整机器汇总：`<数据根>/experiments/asic_numerics_v1/summary.json`；所有本次测量/进度/golden 在其 `measurements_v2` 子目录。原先历史结果重标记的报告已由本报告替代；根目录其他旧产物属于无效旧轮次，不作为本次证据。准确率为本地样本测量，不代替尚未公布的官方600清单；熵数字是明确标注的理论估计，未进行编码器实现或 RTL 面积/周期综合。
