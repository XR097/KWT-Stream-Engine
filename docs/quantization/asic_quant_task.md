# 量化任务说明：为 KWT-1 ASIC 选定数值方案

读完本文即可开工，不需要事先了解硬件讨论的细节。

## 1. 背景

KWT-1 是 12 层编码器（99×64，单头，FFN 64→256→64）。本项目的目标是设计一个只适配该模型的 W4A8 推理加速器。
架构说明见 `docs/arch/kse-microarch.md`。

当前冻结配置是 `all_w4_q15_p7_ln12`：72 个矩阵全 W4、A8、Softmax 指数 Q15 / 概率 P7、LayerNorm Q12/Q12、GELU 256 项表。
本地 4890 条测试 Top-1 为 96.93–96.95%，FP32 为 97.61–97.69%，下降约 0.66–0.76 个百分点。

本任务的目标：在硬件允许的数值空间内，找到“精度分 + 效率分”总和最高的数值方案，并导出可直接用于 RTL 对拍的 golden 包。

## 2. 评分规则（决定取舍的依据）

**精度分 10 分**（赛题指南第 10 页）：

- Top-1 相对统一浮点参考下降不超过 2 个百分点是合格门槛，超过则整体不合格。
- 达到或超过浮点参考得 10 分，每下降 0.2 个百分点扣 1 分，按比例计。
- 组委会在 600 条评测样本上运行我们提交的软件数值模型，浮点参考使用同一评测集和同一分类头。
- 600 条时 1 条错分约等于 0.167 个百分点，约扣 0.83 分。

**效率分的带宽代价**：加速器的单任务时间由“每任务必须读一遍的参数字数”决定（总线是瓶颈）。
吞吐和能耗两项共 24 分，都按排名比值计，大致与参数字数成反比。用下面的经验换算做取舍：

- 参数总字数每增加 1%，效率分约损失 0.2 分。
- 因此精度提高 0.2 个百分点（+1 分），大约值得付出 5% 的参数字数。

全 W4 时每层参数约 6992 个 32 位字：权重 6144，int32 bias 576，其余约 272。
一个矩阵从 W4 改为 W8，它的权重字数翻倍。各矩阵 W4 字数：q、k、v、proj 各 512，fc1、fc2 各 2048。

**例**：把全部 12 层的 q、k 改为 W8，增加 12288 字，约 +14.6%，约损失 2.9 分。精度至少要提高 0.6 个百分点才划算。

## 3. 硬件允许的数值空间（硬约束）

超出以下范围的方案不能用，或者要单独说明代价。

| 项目 | 允许 | 说明 |
|---|---|---|
| 权重 | 逐矩阵 W4 或 W8，逐输出通道 2 的幂尺度 | 乘法器为 9 位 × 8 位有符号，W4/W8 都原生支持 |
| 激活 | A8 有符号，静态 2 的幂尺度，零点 0 | 不能用 A16 |
| 重定标 | 2 的幂移位 + 最近偶数舍入 + 饱和 | 不能用任意整数乘法尺度 |
| MAC 累加 | 部分和加 bias 后不超过 **24 位有符号** | 硬件累加器为 24 位。原 profile 声明 int32，实测最大 18–19 位，请对新方案逐矩阵报告最大位宽 |
| bias | 按实际范围定宽 | 请逐层报告所需位宽，用于压缩参数流 |
| Softmax 概率 | **≤8 位无符号**（P7 原生） | P11 需要 P·V 拆两遍，注意力阶段周期约增加 1/3。只有精度收益明显时才考虑 |
| Softmax 指数 | 紧凑表（257 项），Q15 | 可改表的位宽或项数，保持 ROM 寻址只用移位和比较 |
| Softmax 除法 | 每元素一次整数除法，商 ≤8 位 | 与 P7 一致 |
| LayerNorm | 参考整数实现：一次 isqrt，每元素一次除法 | 归一化商 ≤17 位有符号；norm_frac、gamma_frac 可调，请报告商和仿射乘积的位宽 |
| GELU | 任意 256 项 int8 表（direct 或 middle） | 每层一张 |
| 残差 | 两路各自对齐移位后相加再饱和到 A8 | 与现有实现相同 |
| 非线性 | 不得在运行时使用浮点 | 现有实现已满足 |

## 5. 实验内容

### 5.1 统一基线

在同一数据划分和同一浮点分类头下，重新测出：

- FP32 参考：验证集（完整验证 4445 条）、测试集 4890 条、本地 600 条检查集。
- 当前冻结配置 `all_w4_q15_p7_ln12`，同样三个口径。
- 全 W8A8（其余同冻结配置），作为精度上界参考。

本地 600 条检查集沿用现有审计脚本的固定索引（每类 50 条）。它只用于估计官方口径的方差，不用于选择。

### 5.2 权重敏感度和混合 W4/W8

1. 逐矩阵单独改 W8（72 项），在验证集上测精度变化，同时记录额外参数字数。
2. 按“每增加 1000 字带来的验证集精度提升”排序，贪心加入 W8 矩阵，得到一条帕累托曲线：
   横轴是参数总字数（或 +%），纵轴是验证集 Top-1。
3. 单项收益不能直接相加，曲线上每个点都要实际评估组合。
4. 也试一下按层整体回退（某层全部 W8）和按类型回退（全部 q/k、全部 fc2 等），看是否有更便宜的结构。

### 5.3 非线性精度

在 5.2 曲线上取 2–3 个代表点，分别试：

- Softmax：P7（基线）、P8（u8 全范围）、P11（仅作对照，标明需要两遍）。
- LayerNorm：norm_frac / gamma_frac 取 12/12、16/16、20/16 等，确认位宽仍在第 3 节范围内。
- GELU：direct 与 middle 表，确认两者逐位等价或给出差异。

### 5.4 无数值改变的参数压缩统计（只统计，不改模型）

这些数字直接用于硬件参数流设计：

- 逐层逐矩阵 bias 的实际范围和所需位宽。
- 逐通道移位码的取值范围。
- W4 权重值的分布和经验熵（逐矩阵，以及按 64 个一组的块熵），用于评估无损熵编码能省多少字。
- 冻结方案下每层、全模型的参数字节数（W4 紧密打包、bias 按实际位宽、其他参数）。

## 6. 选择规则

1. 只用验证集选择。测试集 4890 条在选定后跑一次，用来确认，不得据此回调参数。
2. 目标函数：`精度分(验证集下降) − 0.2 × 参数字数增加百分比`，精度分按第 2 节换算，下降为负时按 10 分封顶。
3. 合格条件：测试集下降 < 2 个百分点、全部 MAC 部分和与 bias 和 ≤24 位、无溢出、所有输出有限。
4. 给出 2–3 个推荐方案：一个目标函数最优，一个参数字数不超过全 W4 的 +5%，一个精度最高但满足约束。最终由我们决定。
